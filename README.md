# Bank Marketing Campaign Response Prediction

## Project Overview
A Machine Learning group project developed at the Sri Lanka Institute of Information Technology (SLIIT) to predict whether bank customers will subscribe to a term deposit based on historical marketing campaign data.

## Objectives
- Predict customer responses to bank marketing campaigns.
- Compare multiple machine learning classification models.
- Identify important factors influencing customer subscription.
- Support data-driven marketing campaign decisions.

## Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- XGBoost
- Matplotlib and Seaborn
- Jupyter Notebook

## Machine Learning Models
1. Logistic Regression
2. Decision Tree
3. Random Forest
4. XGBoost

## Methodology
- Exploratory Data Analysis (EDA)
- Data cleaning and preprocessing
- Feature selection and leakage prevention
- Handling class imbalance
- Hyperparameter tuning and cross-validation
- Model evaluation and comparison
- Threshold optimisation
- Feature importance analysis
- Business value and time-based evaluation
