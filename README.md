# Bank Marketing Campaign Response Prediction

## Project Overview

This project focuses on predicting whether a customer will subscribe to a term deposit after being contacted as part of a bank marketing campaign.

The project uses machine learning techniques to analyse customer information and campaign-related data, compare different classification models, and evaluate their ability to predict customer responses.

The main objective is to support data-driven marketing decisions by helping banks identify customers who are more likely to subscribe.

## Dataset

- **Dataset:** Bank Marketing Dataset
- **Source:** UCI Machine Learning Repository
- **File:** `bank-additional-full.csv`
- **Target Variable:** `y` (Term Deposit Subscription: Yes/No)

The dataset contains customer demographic information, campaign details, and previous campaign outcomes.

1. Clone this repository:


2. Navigate to the project folder:

```bash

```

3. Install the required libraries:

```bash

```

4. Open the Jupyter Notebook:


5. Open the project notebook and run the cells.
